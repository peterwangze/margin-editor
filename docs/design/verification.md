# 视觉验收记录

在 Codex 内置浏览器中通过工具栏打开替换，在示例文档中定位匹配并写回文本。1536×1024 的截图由 Playwright 在生产构建上生成。650×540 的窄窗执行了键盘导航和溢出检查。主参考为内置 ImageGen 生成的 [文档编辑器设计](document-editor.png)。成品截图使用按需打开的 [示例文档](../screenshots/workbench.png) 和真实 [查找及替换](../screenshots/find.png)。

| 对照点 | 设计与成品 |
| --- | --- |
| 主结构 | 文档名、传统菜单、分组工具栏、全宽标签、编辑器与状态栏依次排列。文件树从 View 打开，首次启动可直接输入。 |
| 阅读层级 | UI 使用 Instrument Sans，正文使用 IBM Plex Mono。行号、文档状态、长度、行数、编码和换行有固定位置。实现采用更紧凑的控件尺寸。 |
| 配色 | Paper 使用暖白正文、浅灰工具条和紫色活动标签。Ink 深色主题在设置里切换。 |
| 工具和交互 | 保存全部、打印、剪贴板、撤销、查找替换和分屏都有顶栏入口。命令面板在 Tools 或快捷键中打开。 |
| 输入与结果 | 查找替换停靠底部。搜索模式、匹配数、前后跳转和替换按钮来自实际工作流。 |
| 样例文案 | 默认显示空白文档。截图由帮助菜单的样例文档生成，实际标签以已打开文件为准。 |
| 平台差异 | 桌面窗口使用系统窗口按钮。浏览器截图省略这些按钮。 |
