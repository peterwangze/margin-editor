# 视觉验收记录

在 Codex 内置浏览器中使用菜单打开替换，输入并替换示例 JSON 的版本值，确认文本、计数和未保存标识更新。1536×1024 的可复现截图由 Playwright 在生产构建上生成，650×540 的窄窗也执行了可达性和溢出检查。主参考为内置 ImageGen 生成的 [工作台设计](concept.png)。成品使用真实 [默认工作台](../screenshots/workbench.png) 与 [查找及替换](../screenshots/find.png) 截图。

| 对照点 | 设计与成品 |
| --- | --- |
| 主结构 | 标题、菜单、工具栏、活动栏、文件面板、标签、编辑器和状态栏顺序一致。1536 px 时扩大侧栏及控件比例以匹配参考。 |
| 阅读层级 | UI 使用 Instrument Sans，正文使用 IBM Plex Mono。行号与正文对齐，文件名、选中状态、编码和换行在各自固定位置。 |
| 配色 | 使用墨紫背景、淡紫焦点、绿色字符串、暖色数字和低对比分隔线。移除概念图中轻微的渐变与装饰纹理。 |
| 工具和交互 | 保留 New、Open、Save、剪切、复制、粘贴、撤销、重做及命令入口。增加可用的分屏、整词、搜索选项和书签。 |
| 输入与结果 | 文档上方的两行搜索保留，状态数和高亮来自实际运行。取消、无结果、正则错误和不可替换状态均有对应反馈。 |
| 首屏文案 | 保留 Margin、菜单名、示例文件名与命令入口。示例显示 Demo，文件面板列出实际打开的三份样例。新增 Open Folder 和只读/未保存状态以支持真实工作流。 |
| 平台差异 | 系统窗口按钮由桌面运行时提供；浏览器截图无原生按钮。命令面板作为独立、可关闭的焦点层显示，打开时覆盖工作台。 |
