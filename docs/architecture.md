# Margin 架构与界面

Electron 提供系统文件对话框、剪贴板、打印和独立的 Chromium 环境。React/Vite 绘制工作台，CodeMirror 6 管理文本、增量语法树、选择区、编辑事务与每个文档的撤销状态。选择 Electron 的主要原因是离线包可以携带运行时，三平台界面也使用相同引擎。

主进程拥有文件读写、目录搜索、进程启动和快照，预加载以固定方法提供 IPC。界面不启用 Node 集成，限制导航、新窗口和权限。工作区搜索在独立线程运行并可终止。搜索结果缓存由主进程持有；批量写入先确认各文件字节指纹，再按文件执行同目录原子替换并报告进度或部分失败。普通保存也核对读入时的文件版本。会话独立于文档保存，写入应用数据目录。

内部文档使用 LF 和 UTF-16 位置，与 CodeMirror 对齐。解码记住输入编码、换行及磁盘指纹；转码时先验证往返，再将换行转换落实到输出字节。混合换行记录按现有行分隔符保存，显式 EOL 转换可以统一换行。超大文件采用显式读取上限，降低内存风险。每个视图独立持有滚动与选择，文档切换保留编辑状态。

## 视觉规格

参考见 [主界面设计](design/concept.png)。墨紫工作台使用 `#191721` 文档背景、`#201e2b` 侧栏、`#262333` 活动面板、`#b7a0f7` 焦点、薄分隔线及浅色正文。Instrument Sans 用于界面，IBM Plex Mono 用于内容，两者随安装包分发。窗口标题、菜单、文件工具栏和键盘可达的命令入口构成顶部。左侧活动栏和文件面板可收起，活动标签带下划线及未保存标记。搜索与替换位于文档上方，状态栏提供跳转、编码和换行操作。命令面板可通过 Esc 返回当前编辑器，默认启动不自动打开。

组件对应工作台、文档标签/编辑视图、目录面板、搜索条和对话框。状态栏及菜单使用共享命令入口。系统提供原生窗口按钮，macOS 使用系统窗口布局。
