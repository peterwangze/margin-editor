# Margin 架构与界面

Electron 提供系统文件对话框、剪贴板、打印和独立的 Chromium 环境。React/Vite 绘制工作台，CodeMirror 6 管理文本、增量语法树、选择区、编辑事务与每个文档的撤销状态。选择 Electron 的主要原因是离线包可以携带运行时，三平台界面也使用相同引擎。

主进程拥有文件读写、目录搜索、进程启动和快照，预加载以固定方法提供 IPC。界面不启用 Node 集成，限制导航、新窗口和权限。工作区搜索在独立线程运行并可终止。搜索结果缓存由主进程持有；批量写入先确认各文件字节指纹，再按文件执行同目录原子替换并报告进度或部分失败。普通保存也核对读入时的文件版本。会话独立于文档保存，写入应用数据目录。

内部文档使用 LF 和 UTF-16 位置，与 CodeMirror 对齐。解码记住输入编码、换行及磁盘指纹。转码时先验证往返，再将换行转换落实到输出字节。混合换行记录按现有行分隔符保存，显式 EOL 转换可以统一换行。超过 48 MiB 的文件按约 1 MiB 分页。UTF 和受支持的单字节编码可编辑当前页并跨页搜索。保存时核对页摘要及文件身份，再流式复制未改动的字节，完成后原子替换。每个视图独立持有滚动与选择，文档切换保留编辑状态。

## 视觉规格

参考见 [文档编辑器设计](design/document-editor.png)。Paper 使用 `#fdfcfb` 文档背景、`#f5f3f0` 控件背景和紫色焦点。Ink 为深色方案。Instrument Sans 用于界面，IBM Plex Mono 用于内容，两者随安装包分发。当前文档标题、菜单、分组工具栏和全宽标签位于顶部。默认启动聚焦空白文档，目录树、目录搜索和大纲由菜单按需打开。活动标签有顶部色线及未保存标记。查找与替换停靠在编辑器下方，状态栏提供跳转、编码和换行操作。

组件对应工作台、文档标签/编辑视图、目录面板、搜索条和对话框。状态栏及菜单使用共享命令入口。系统提供原生窗口按钮，macOS 使用系统窗口布局。

文本检查器在独立线程对打开时的编辑快照做 Unicode 分词、字素计数和清理预览。选区以文档偏移记录，清理只写选区内的字符，保留编辑器跟踪的换行。应用前核对编辑快照，一次编辑事务提交并单独记入撤销历史。大文件只检查当前页，页末未完的行跳过行尾清理。重新打开 Unicode 文件时，编码标签反映磁盘上的 BOM，改变 BOM 由显式转码操作完成。
