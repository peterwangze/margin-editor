# Margin 发行验收清单

每次发行以候选标签及提交为单位复制运行记录。记录系统版本、架构、安装包哈希、执行人或 CI、实际输出与缺陷链接。状态使用 `通过`、`失败`、`未验证`、`未实现`。合并新功能或修复时新增用例或更新既有步骤，保留 ID。回归测试在独立用户目录和临时文件夹执行。

## 发布阻塞项

要标记为满足 Notepad++ 完整功能验收，F01–F12 的子项都需要证据。下列差距尚未通过，发行号采用 `0.9.0`，GitHub 标为预发行版。

- Windows DLL/Scintilla 互操作、插件目录和安装管理，Windows Shell 注册、完整 Notepad++ CLI 和安装器参数。
- Boost 正则及替换语法兼容、完整书签/标记样式、项目列表 XML、会话 XML、快捷键 XML、主题 XML 和函数规则导入。
- 完整 UDL 运算符、嵌套分隔符、折叠和分组配色，完整代码页和内建 lexer 清单，参数提示和函数补全定义迁移。
- 原版编辑和设置菜单中的长尾能力，包括虚拟空间列粘贴、完整宏动作、GUI 本地化、自定义菜单/工具栏，以及 Windows 专有的鬼打字和系统集成。
- 48 MiB 以上文件的分段浏览与编辑、全部平台及架构的离线人工安装、IME、屏幕阅读器、高对比度和签名验证。

安装包的 CI 通过表示已生成工件，带 Smoke 步骤的架构还验证了包内应用的真实编辑与磁盘操作。完整安装程序、系统文件关联和卸载用例需要独立证据。
